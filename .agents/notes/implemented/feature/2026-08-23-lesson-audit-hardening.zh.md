# Agent Note：课程审计加固——重编号、证据去重与实验室输入重置

Status: implemented

[English](2026-08-23-lesson-audit-hardening.md) | 中文

## Problem

一次全仓库审计（逐页读完 37 个课程正文、文件索引生成器和全部 15 个互动实验室，对照 15 条可用性启发式）发现三类门禁抓不到的缺陷：

1. 课程撞号：两个 `28-` 和两个 `29-` 文件让按编号导航产生歧义，START-HERE 路由表也从未链到最新的两节互动课。
2. 跨页事实漂移：快照摘要与自己的夹具示例矛盾（23 课）、新手任务单上三个互相矛盾的时长（25 课）、widget 降级死锚点（14 课）、过期课程范围（09 课）、四条 bullet 配“三条规则”（05 课）、Debug 工具两种路径（36 课，原 29）、预测题旁直接印着答案（33 课），以及文件索引导航表缺一整行、十六条过期条目数合计 2,756 而非 2,973。
3. 行文公式密度与交互缺口：四域隔离免责声明在四个页面逐字出现，26/27 两课携带近乎复制的证据分级排比，32 课破坏全书无人称体例，而所有实验室都不提供输入重置——清掉 `#state=` 只能手改地址栏。包图的滚轮缩放还会劫持页面滚动。

## Decision

- 将 `28-最小插件工作台` 改号为 `35-`，`29-研究与-Debug-协作` 改号为 `36-`；保留被 `verify-study-entry` 和学习契约锚定的两个编号。同步全部 15 处引用，包括 quiz 题库的课程 id 和实验室回链。
- 在事实发生处逐一修复。23 课写明摘要数字属于哪份文件；25 课与 START-HERE 统一为 5 + 10 = 15 分钟；降级锚点指向真实标题；33 课把答案收进 `<details>` 门。
- 收敛共享边界：22 课是四域隔离免责声明的唯一权威表述，23/26/27 指向它。证据分级只保留决策卡（27）一处，26 课改为链接。32 课去除第一人称，并把个人判断链接到 34 课。
- 在 `study-lab-kit.js` 新增共享的 `installInputReset(button, form, { onReset })`（鸭子类型守卫，无 DOM 测试环境可安全导入），并为每个实验室表单接上「恢复默认输入」按钮，两个独立页也不例外。包图滚轮缩放对修饰键放行。
- 独立的 code-mode 与 research-debug 页面在 tokens 与私有样式之间加载 `study-lab-shell.css`：shell 层的焦点态、forced-colors 补丁和触达面积打磨得以传导，选择器优先权仍归私有样式。
- Quiz 题库 e/f 同步新编号和新标题；README 双语对的哈希在链接文本变化后重新录制。

## Alternatives considered

**通过与现有编号交换来保持侧栏位置。** 否决：会级联波及已被占用的编号；`studySection()` 只读数字前缀，追加 35/36 即可保持分组稳定。

**由生成器输出文件索引导航表并加门禁锁死。** 这是正确的长期修法，但另一条并行工作流正在重构生成器（`migrate-index-legend`）；本变更改为依据全部 67 个生成页头部手工校正表格，避免冲突且数字经过核验。

**把两个独立实验室完整迁移到 shell 标记。** 暂缓：私有样式表重定义了同名类，迁移标记需要浏览器 QA；样式分层以零风险拿到大部分收益。

## Consequences

按编号导航不再歧义，每个互动实验室都有显式重置，且同时清理可分享的状态链接。边界声明各自只有一个可引用的家，基线迁移时不再需要四处同步同一段免责文案。`study-lab-shell.css` 中待提交的 `.stepper` 样式随本次落地——已提交的 guard-loop 步进 UI 正引用它们；四个兄弟实验携带等价的待提交步进标记，由同一批测试覆盖。重录两对 README 哈希后，translation pairing 以 966 对全绿通过。
