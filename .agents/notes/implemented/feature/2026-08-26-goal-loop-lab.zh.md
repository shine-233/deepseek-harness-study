# Agent Note：Goal 循环实验室

Status: implemented

[English](2026-08-26-goal-loop-lab.md) | 中文

## 问题

路线图首要缺口（37 课是全套最薄的一页）：tool-ralph 的固定脚本——每轮启动一个全新结构化输出子代理，只携带不可变目标与上一轮有界交接摘要，continue/complete/blocked 三值出口——此前没有任何可交互的演示。

## 决策

按 acp-lab 四件套模式新建纯模型/视图/页面。逐拍帧序列里每轮三拍（启动全新子代理、结构化回报、交接入库），交接超预算时截断可见；预算耗尽是独立出口帧，绝不冒充完成。三种结局模式对应真实可能：两轮收敛、一轮完成、持续受阻到预算耗尽。旋钮有三个：轮数上限（显示夹 1–8，上游默认 256）、交接字符预算（40–400）、结局模式。独立校验从帧直接重算三条硬规则：交接永不超预算、轮数不超上限、完成判定必须来自 complete 回报。预测门问「第一轮没做完，决定再来一轮的是谁」，错误选项正是两种常见误读——模型自己续轮、子代理共享记忆。

注册走两条路：进度名单以「HEAD+goal-loop」方式暂存（工作文件在并行修改中，未碰对方内容），步进清单直接登记。37 课链接等并发清扫落地后补。

## 后果

study-tools 全套 864 条测试绿；新文件零碰撞落在并发 sweep 之外。
