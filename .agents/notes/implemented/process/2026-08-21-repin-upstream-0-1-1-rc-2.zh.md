# Agent Note: Re-pin the study baseline to upstream 0.1.1-rc.2

Status: implemented

[English](2026-08-21-repin-upstream-0-1-1-rc-2.md) | 中文

## Problem

教材固定在 `47f943859bef60e4160492346772ded9b24f765a`（根包 `0.1.0-rc.5`，2026-08-13）。上游已前进 854 个提交，npm 已发布 `0.1.1-rc.2`（2026-08-21）。读者拿课程对照当前 npm 包时会遇到正文从未提到的接口，而首页没有任何一句话说明教学描述的是哪个基线。

## Decision

固定提交改为 `aa6c361a972c8369148dea7380bb5c21c24e07ec`——`release(dsh): 0.1.1-rc.2` 提交：

- 源码索引从该提交的完整归档重新生成：2,973 个源文件、67 个索引页（此前 2,756 / 66；SQL 进入扩展名白名单，新增 56 个文件）。
- 包图 fixture 从新清单重新生成：227 个包、50 个组、1,124 条 peer 边（此前 219 / 49 / 1,089）。第 02 课、包图实验文案、模型注释和 3D 场景标签都改用新数字，包括重算过的「前 14 个组占 72% 行数、28% 组数」。
- 手写材料中 201 处旧 commit SHA 链接全部指向新提交；`UPSTREAM.md` 记录新版本、日期、tree 规模（7,903 个文件）和分扩展名计数。
- 清扫过期派生数字：14 篇课程里的索引计数、第 32 课的页面/测试计数、以及新 SHA 旁边仍写着 `0.1.0-rc.5` 的版本字符串。
- 第 14 课的证据范围声明现在写明：人工对照完成于上一个基线（2026-08-16），迁移只复核了链接路径存在，没有逐行复读差异。
- 首页状态条增加基线行：上游 `0.1.1-rc.2`、提交 `aa6c361a`，并链接到第 18 课的迁移流程。

迁移后的验证：`verify-source-index`（2,973/2,973/0 错误）、`audit-source-index-quality`、`verify-study-links`（41 份手写材料、0 路径错误）和包图模型测试全部通过。

## Alternatives considered

- **留在 rc.5 只加横幅。** 否决：差距已经是一个 minor 线加 854 个提交；每写一篇新课，能复现它的读者都在变少。
- **固定到 master HEAD（`b150a55`）。** 否决：master 每天在动；release 提交可以从 npm 复原，给索引一个稳定目标。
- **等 0.1.x 出稳定版。** 维护者判断后否决：Developer Preview 迭代快，但迁移流程已脚本化、重复成本低；推迟会让漂移复利。

## Consequences

课程、索引条目和实验 fixture 描述的树，与读者从 `npm pack @deepseek-ai/dsh@0.1.1-rc.2` 拿到的树一致。断言 rc.5/rc.6 差异行为的手写正文只在被检出处更新；这次迁移的语义审查是有边界的——41 份材料的链接路径存在性已验证，但基线间的深层行为差异除课程点名处外仍未逐行复审。首页基线行把这个边界摆给读者看。
