# Agent Note: 增加直接学习入口与按证据排序的研究路线

Status: implemented

[English](2026-08-16-study-front-door-and-research-roadmap.md) | 中文

## Problem

Pages 已经发布完整的中文学习路线和逐文件索引，但第一次来的读者仍可能把完整目录误认为起点。剩余研究工作也需要一个长期可维护的顺序，把静态文档证据和宿主、provider、运行时证据分开。

## Decision

学习路线新增一张 15 分钟任务单，引导读者从首页开始，经过两篇基础课、选择一条路线、打开一个固定版本源文件，并写下四句话的学习记录。另新增一张路线图，把宿主可见性观测和真实工具可见性 A/B 测量排在人工索引批次、社区审核、示例插件、网页体验、仓库治理、依赖分类和 Actions 维护之前。Pages 首页、仓库 README 和 START-HERE 互相链接这两个入口，中文站点标题明确标记为教材。

## Alternatives considered

**只保留现有路线表。** 路线表能描述选择，但不能让不知道如何选择的读者得到一个可观察的第一份产出，因此保留独立任务单。

**把所有剩余工作写成平铺 TODO。** 平铺清单会隐藏“宿主导出的可见性快照”与“可信 A/B 实验”之间的前置关系，因此路线图记录前置条件和验收证据。

**增加私有观测 Hook，让路线图立刻可运行。** 这会把学习仓库变成运行时修改，也会诱导普通插件依赖私有状态；路线图把责任留给宿主或明确标注的 patched fork。

## Consequences

网页前门变得更明确，同时保留 66 个生成索引页作为折叠的参考面。读者可以完全在 GitHub Pages 中完成第一次练习，但任务单和路线图明确保留证据边界：网页阅读、文档门禁、宿主快照、provider 测量和真实 DSH 运行属于不同证据类别。新路线图是当前优先级，不证明其中 P0 或 P1 实验已经运行。
