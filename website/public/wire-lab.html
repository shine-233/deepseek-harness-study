每一句请求都有编号，每一句回应都认领同一个编号。

SDK 客户端和 runtime server 之间是按行分隔的 JSON-RPC：request 带 id、response 认领同一 id；notification 没有 id，单向推送不等待回应。服务端错误走 response 通道（JsonRpcResponseError），行传输保持可用——协议内失败不等于断线。initialize 必须是对话的第一句，此前的业务请求会被拒绝。
