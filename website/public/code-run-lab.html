程序失败不是异常路径：error 住在结果字段里。

CodeRuntime 把一段程序交给执行基底跑：run() 永远 resolve 一个 { value?, logs, error? }。六种失败类彼此正交——exception、timeout、abort、worker-exit、invalid-output、output-limit，谁先到就报哪一种，互不混用。binding 命名空间要过三道检查：标识符形状、非保留字、不占后端自有槽位；$tools 这类 JS 专属拼写在任何后端都被拒绝。切剧本和命名空间，逐步推时间线。
