NESTED SETS

三个同心集合

containment = level

嵌套本身就是数据结构：一个工具画在它能到达的最内层里。上面三个控件各自收窄一层，可以逐个试：勾掉一个 Bundle，它的工具会掉到最外层；把 agent 作用域换成「只读研究」，write 和 execute 工具会停在「已注册」这一圈；把执行策略换成「只允许读」，它们会停在「模型可见」这一圈。把鼠标停在任意一个工具上会显示它被谁挡住。颜色只分“到达最内层”和“被挡住”两档，不编码 Bundle——Bundle 用文字标出。

WHERE THEY STOP

十二个工具各自停在哪一层

count per level

条的长度是数量，四段之和恒等于清单里的工具总数——oracle 会检查这一点。三道收窄各挡下多少，一眼可比。

INDEPENDENT ORACLE

嵌套关系由 oracle 核对

set audit

oracle 不读页面上任何已渲染的内容。它从工具数组重算三个集合，检查两条子集关系、数量单调、每个被挡工具都有原因、层级与标记一致，以及四种去向之和等于总数。
