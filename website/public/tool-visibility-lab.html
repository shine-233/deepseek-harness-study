嵌套集合

三个同心集合

包含关系 = 层级

嵌套本身就是数据结构：一个工具画在它能到达的最内层里。上面三个控件各自收窄一层，可以逐个试：勾掉一个 Bundle，它的工具会掉到最外层；把 agent 作用域换成「只读研究」，write 和 execute 工具会停在「已注册」这一圈；把执行策略换成「只允许读」，它们会停在「模型可见」这一圈。把鼠标停在任意一个工具上会显示它被谁挡住。颜色只分“到达最内层”和“被挡住”两档，不编码 Bundle——Bundle 用文字标出。

点击任意一个工具（同心图色块或表格行），追踪它走到哪一层、被哪道收窄挡下；再点一次取消。

独立校验 不读页面上任何已渲染的内容。它从工具数组重算三个集合，检查两条子集关系、数量单调、每个被挡工具都有原因、层级与标记一致，以及四种去向之和等于总数。
