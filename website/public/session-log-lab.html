          schema 17 · 应用 id DSHP（基线 aa6c361a 值；本地源码树可能已演进）

          上游的 SQLite 会话库把连续的流式增量打包成一条物理行：信封只存首序号和首时间戳，其余时间用增量数组还原；data 不足 4096 字节直接存文本，达到阈值才进 zstd 分支。打包行的 source_event_seqs 列按「差分 + zigzag + base-128 varint」逐字节编码（输入的有序性由生产方保证），表里给的就是真实字节，可解码还原。切一下开关，看同一条流怎么落库。
